# Лабораторная работа №3

## Описание

Программа предназначена для анализа противоречий и согласования двух кластерных ранжировок на основе метода согласования экспертных оценок.

Программа выполняет следующие вычисления:

**Анализ кластерных ранжировок** — обрабатывает две ранжировки, представленные в JSON-формате, где:
- Отдельные элементы представляют объекты с уникальным порядком
- Списки элементов в квадратных скобках представляют кластеры неразличимых объектов

**Построение матриц предпочтений** — для каждой ранжировки строится бинарная матрица, где элемент `[i][j] = 1`, если объект i не хуже объекта j (лучше или неразличим).

**Выявление противоречий** — находит пары объектов, для которых эксперты имеют противоположные мнения:
- Если один эксперт считает объект A лучше B, а другой — B лучше A
- Противоречивые пары образуют ядро противоречий

**Формирование согласованного порядка** — на основе согласованных сравнений строится матрица согласованного порядка, при этом объекты, входящие в ядро противоречий, переводятся в отношение эквивалентности.

**Определение кластеров эквивалентности** — объединяет объекты с неразличимыми отношениями в кластеры с обеспечением транзитивности.

**Упорядочивание кластеров** — определяет порядок между кластерами на основе согласованных предпочтений экспертов.

**Формирование результата** — возвращает JSON-строку, содержащую:
- ядро противоречий
- согласованную кластерную ранжировку

## Теоретическая основа

Метод основан на теории кластерных ранжировок и согласования экспертных оценок и включает следующие этапы:
1. Представление ранжировок в виде матриц предпочтений
2. Выявление ядра противоречий между экспертными оценками
3. Формирование согласованного порядка с учётом противоречий
4. Выделение кластеров эквивалентности объектов
5. Упорядочивание кластеров и построение итоговой ранжировки
