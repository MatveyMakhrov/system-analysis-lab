# Лабораторная работа №4

## Описание

Программа предназначена для реализации алгоритма нечеткого управления на основе метода Мамдани и вычисления оптимального управляющего воздействия для системы регулирования температуры в помещении.

Программа выполняет следующие вычисления:

**Фаззификация входных данных** — преобразует текущее числовое значение температуры в степени принадлежности нечетким множествам лингвистической переменной «температура» (например: холодно, комфортно, жарко), заданным кусочно-линейными функциями принадлежности.

**Применение правил логического вывода** — использует правила нечеткого управления вида
__«если температура — …, то уровень нагрева — …»__, реализованные по методу Мамдани:
* вычисляется уровень активации каждого правила;
* формируется нечеткий вывод для соответствующего терма управления.

**Агрегация нечетких выводов** — объединяет результаты всех активированных правил в единое нечеткое множество «оптимальное управление» с использованием операции максимума.

**Дефаззификация** — преобразует нечеткий вывод в конкретное числовое значение управляющего воздействия с использованием метода первого максимума.

**Формирование результата** — возвращает вещественное число, представляющее оптимальное значение уровня нагрева.

## Теоретическая основа

Алгоритм реализован на основе теории нечетких множеств и нечеткой логики, согласно следующим положениям:
1. Использование лингвистических переменных и термов для описания входных и выходных параметров системы.
2. Задание функций принадлежности в виде кусочно-линейных (трапециевидных) функций.
3. Применение метода Мамдани для нечеткого логического вывода:
* операция min для активации правил;
* операция max для объединения нечетких выводов.
4. Дефаззификация результата методом первого максимума, при котором выбирается первое значение управляющей переменной, для которого функция принадлежности достигает максимума.
